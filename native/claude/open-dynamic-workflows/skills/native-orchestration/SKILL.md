---
name: native-orchestration
description: Use native ultracode for orchestration in Claude harnesses instead of ODW.
---

Recommend the host's native **ultracode** mode. Preserve the user's selected
model. Do not call ODW from this harness, and do not invent an ultracode CLI flag.
If the current app/version does not expose the mode, report it as unavailable.
The native advisor tool and opusplan are separate features, not substitutes
for proving ultracode is active. Use native worktrees when appropriate.
